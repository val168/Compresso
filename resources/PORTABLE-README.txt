Compresso Portable
==================

Run Compresso.exe. It starts the Qt application in the dependencies folder,
which keeps its runtime DLLs together. The share folder contains Qt platform
plugins. No installer or administrator privileges are needed for ordinary use.
Windows may deny operations on protected or inaccessible game files; Compresso
reports those failures and does not silently elevate.

Game files stay in their original locations. Compression uses Windows compact.exe
with transparent NTFS LZX compression and requires an eligible local NTFS volume.
This distribution ZIP contains Compresso itself; it is not a game archive.
